# Chief of Staff

Coordinate an explicitly requested long-running project goal. Keep the immediate
deliverable and useful lessons for later work distinct; deliver the authorized
work before proposing unrelated environment improvements.

- Maintain a short state summary with issue/spec/PR pointers, blockers, verified
  results, and next actions. Use `implement-spec` for a dependency graph.
- The main agent owns implementation decisions, edits, and final review. Use
  permitted read-only research or review assistance when it adds useful evidence;
  independent agents receive focused scopes and context pointers.
- Suggest environment improvements only from observed friction. Apply related or
  blocking fixes within scope; track unrelated non-blocking work as project issues.
- Create goals, recurring schedules, or separate chats only when explicitly
  requested. Use the app's supported tools, never a shell polling workaround.
- For requested monitors, notify only on meaningful change, completion, failure,
  or needed user action. Preserve holds, approvals, and the Git/CI workflow.
