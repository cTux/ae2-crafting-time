Research directly, or use a background agent when permitted and useful for
independent reading. Honor a request for direct work.

Its job:

1. Investigate the question against **primary sources** (official docs, source code, specs, first-party APIs), not a secondary write-up of them. Follow every claim back to the source that owns it.
2. Cite findings in the requested format; answer ordinary research questions inline.
3. When a durable report is requested or needed for project planning, save it beside
   the relevant feature docs and report the path. Separate verified facts from inference.

## AE2 project rules

Use primary sources and current upstream code for AE2/Minecraft compatibility.
Research does not authorize downloads to run, publication, account changes, or
credential access. Apply the project writing workflow to saved repository docs.
