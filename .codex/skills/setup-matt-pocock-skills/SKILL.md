configured: normal use does not require a setup interview.

1. Read `AGENTS.md`, `docs/agents/issue-tracker.md`,
   `docs/agents/triage-labels.md`, and `docs/agents/domain.md`.
2. Compare them with the actual Git remote, existing GitHub labels, feature

   Ask only about a material unresolved choice, not facts already in the repo.

5. Follow the project writing workflow, then report actual changes and checks.

new labels, changing the hook/test ordering, or editing global skill settings.
