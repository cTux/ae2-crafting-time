# Triage roles and project labels

[AGENTS.md](../../AGENTS.md#issue-labels) is the label authority. Reuse its existing
priority, effort, hold, and workflow labels; preserve unrelated labels on edits.

Upstream bug/enhancement categories and needs-triage, needs-info, ready-for-agent,
ready-for-human, and wontfix states are prose assessments here, not extra labels.
Put an assessment in the issue body or an authorized triage comment. Readiness
describes how complete the requirements are; `backlog` still holds implementation.
Use `in/progress` only for active work. Do not create category, area, model, or
wayfinder labels or prefix issue titles with a type.
