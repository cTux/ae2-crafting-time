# Підтримка аддонів

Хімічні ключі Applied Mekanistics використовують ті самі мілівідра, що й
рідини AE2, тому швидкість і TTC лишаються змістовними. Сумісні crafting CPU з
AdvancedAE, NeoEco та AE2 Lightning Tech також можуть передавати звичайні події
профілювання на підтримуваних версіях.

Наприклад, підтримуваний CPU аддона з хімічним рецептом навчає історію мережі й
результату, а потім показує TTC на звичайних екранах AE2. Аддони не стають
обов'язковими: якщо один відсутній або несумісний, мод пропускає лише його
адаптер. Екрани аддона не отримують позначки без окремо зазначеної UI-інтеграції.
Після зміни встановленої версії аддона потрібен перезапуск.

Для Data Energistics 3.3.5 на NeoForge 1.21.1 є окремий параметр
**Data Energistics Trinity**, увімкнений за замовчуванням. Він стосується
справжнього робочого CPU Trinity, а не CPU, який лише приймає замовлення.
Загальний параметр Profiling теж керує цим профілюванням. Вимкнення зупиняє
відстеження поточного завдання; після повторного ввімкнення нове завдання
починається без старих незавершених даних, а вивчена історія зберігається.
Рідний екран плану Trinity може показувати вивчений TTC у рядку матеріалу,
а звичайний екран Status — оцінку того самого робочого CPU. Перевірка пакетної
роботи, повторного використання матеріалів, перезапуску та вигляду ще триває
в межах задачі #740. Це не означає підтримку всіх машин або режимів Data Energistics.
