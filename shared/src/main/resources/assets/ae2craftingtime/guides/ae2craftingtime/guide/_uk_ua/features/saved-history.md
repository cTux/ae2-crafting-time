# Збережена історія

Завершені зразки швидкості зберігаються зі світом окремо для кожної
AE2-мережі та результату. Для результату лишається налаштована кількість
найновіших зразків, тому після перезапуску не потрібно вчити кожен рецепт з нуля.

Незавершені партії, поточні таймери простою, недавня паралельна місткість і
точність завдань існують лише до перезапуску. Окремі збережені стани можуть
показувати Delayed, Waiting, No provider та No power, доки їх не замінять
нові спостереження; самі по собі вони не відновлюють таблички попереджень.
Видалені моди можуть залишити нешкідливі записи, які не показуються без
відповідного результату. Скидання стирає історію одного результату для навчання заново.

![Збережені виробничі зразки в підказці TTC](images/ttc-production-sample-details.png)

*Тестові збережені зразки показують обмежену історію, яка переживає збереження світу.*
