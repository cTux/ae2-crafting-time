# AE2 Crafting Time

AE2 Crafting Time показує приблизний час автокрафтів AE2 і допомагає помічати затримки. Мод навчається на результатах роботи вашої мережі, тому для нових крафтів оцінки часу ще може не бути. Він не прискорює роботу машин.

Відкрийте план крафту перед запуском завдання або стан крафту під час його виконання, щоб побачити доступні оцінки часу. TTC означає «час виготовлення». Це приблизний прогноз, а не точний термін: результат залежить від машин, спільного навантаження та швидкодії сервера.

Почніть із [розділу 1: Ваша перша оцінка часу](getting-started.md).
