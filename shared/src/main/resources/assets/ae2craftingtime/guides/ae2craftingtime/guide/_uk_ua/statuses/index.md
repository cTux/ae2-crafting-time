# Розділ 3: Стани

Позначки стану крафту пояснюють, що робить вибраний CPU або що його зараз
блокує. Почніть згори й відкрийте першу позначку, яку бачите:

1. [Немає місця](no-space.md)
2. [Без провайдера](no-provider.md)
3. [Немає енергії](no-power.md)
4. [Немає каналу](no-channel.md)
5. [Заблоковано](locked.md)
6. [Вхід заблоковано](input-blocked.md)
7. [Немає приймача](no-target.md)
8. [Очікування](waiting.md)
9. [ЗАТРИМКА](delayed.md)
10. [Даних ще немає](no-data-yet.md)
11. [Оцінка TTC на кшталт ~12 с](estimated.md)

У плані крафту перед запуском є окремий діагноз: [Циклічне](recurrent.md).
Він означає доведену самозалежність рецептів, а не спільний пріоритет зі станами
виконуваного завдання вище.

Порядок важливий. `Немає місця` стосується вже збереженого результату. Решта
блокувальних позначок стосується запланованих партій; активна партія того самого
рядка може завершитися. Мод показує спостережену умову, а не діагноз конкретної
машини.
