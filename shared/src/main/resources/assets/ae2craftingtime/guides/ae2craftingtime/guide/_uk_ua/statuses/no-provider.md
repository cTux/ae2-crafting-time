# Без провайдера

**Позначка:** `Без провайдера`

Цей стан з'являється для запланованого рядка, коли AE2 не знаходить точного
закодованого шаблону в під'єднаному провайдері шаблонів. Він випереджає інші
причини блокування запланованої роботи. Активні партії можуть завершитися.

## Що перевірити

1. Відновіть провайдер і його з'єднання з мережею.
2. Поверніть закодований шаблон до доступного провайдера.
3. Переконайтеся, що шаблон досі створює запланований результат.

Позначка зникає, коли наступне оновлення знову знаходить точний шаблон, або коли
завдання завершується чи скасовується. Вона не називає конкретний провайдер;
інший справний рецепт того самого результату не очищує відсутній шаблон.

![Рядок «Без провайдера» й порада щодо шаблону](images/crafting-status-no-provider.png)

*Активна партія може завершитися, але заплановані партії втратили шаблон.*
