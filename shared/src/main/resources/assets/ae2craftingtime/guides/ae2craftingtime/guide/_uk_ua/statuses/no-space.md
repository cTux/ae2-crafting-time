# Немає місця

**Позначка:** `Немає місця`

Цей стан з'являється у вікні стану крафту, коли CPU утримує готовий результат,
але не може повернути його до доступного для запису сховища ME. Він має найвищий
пріоритет, бо предмети вже існують і залишаються всередині CPU.

## Що перевірити

1. Звільніть місце в комірці, яка приймає цей предмет.
2. Додайте доступне для запису сховище або виправте його розділ і пріоритет.
3. Перевірте живлений шлях від CPU до сховища.

Позначка зникає, коли результат потрапляє до мережі ME. Додавання місця може
очистити її без повторного відкриття екрана. Вона не називає заповнену комірку й
не означає, що в машині обробки немає місця для результату.

![Рядок «Немає місця» й порада щодо сховища](images/crafting-status-no-space.jpg)

*Результат у CPU не може повернутися до заповненого сховища ME.*
