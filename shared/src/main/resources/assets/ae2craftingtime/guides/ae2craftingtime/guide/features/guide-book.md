# The guide book

Craft this guide from a book, an uncharged Certus Quartz Crystal, and a clock in
any order. Hold it and use it to open the guide. The contents are packaged with
the mod, so reading and searching do not need an internet connection.

Use the home and history controls to navigate, the contents tree to move between
chapters, and search to find a feature or status name. Select Ukrainian in the
guide language control when you want the matching translated tree. For example,
search for `confidence` and open the result to learn why a TTC has a question
mark. Forge 1.20.1 needs optional GuideME; Fabric 1.20.1 uses AE2's bundled guide
renderer. Modern NeoForge uses GuideME. Without the optional renderer on Forge
or NeoForge, the rest of AE2 Crafting Time still works and no broken recipe is
shown.
